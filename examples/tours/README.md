# Guided tour projects

These are the same starting projects used by Help → Guided tours. Open an `.atheditor` directly to experiment independently, or run its guided tour in the editor. Use Previous to revisit a step and Next to continue. At the end, close the guide to keep editing the practice, download it, or explicitly return to your prior project.
